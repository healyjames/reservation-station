# UI components

Owned daisyUI-backed Preact components in `src/frontend/shared/components/ui/`. Import them from `@shared/components/ui`.

Conventions: see "UI components" in `.claude/docs/architecture.md`. Build new ones with `/ui-component <daisyUI name>`. Props lists names only; the source is the reference.

| Component | daisyUI category | Props | Consumers |
| --- | --- | --- | --- |
| Loading | Feedback ([loading](https://daisyui.com/components/loading/)) | `size`, `label` (`null` or `''` = decorative), `<span>` attributes | ui/Button (replaces `Spinner`) |
| Button | Actions ([button](https://daisyui.com/components/button/)) | `variant` (primary, secondary = neutral outline, error, ghost), `size` (sm, md), `shape` (square, circle), `block`, `isLoading`, `type` (default `button`), `<button>` attributes | none yet (replaces `Button`) |
| Icons (`ui/icons/`, import from `@shared/components/ui/icons`, not the ui barrel) | none (inline SVG adapted from [Lucide](https://lucide.dev) v0.460.0, ISC) | `title` (accessible name for a standalone meaningful icon; without it the icon is `aria-hidden`. Inside a button, name the button instead), `size` (px; default `1em`, the surrounding text size), `<svg>` attributes. Exposes `data-icon="<lucide-name>"`. Icons: ArrowLeft, ArrowRight, CalendarDays, CalendarX, ChevronLeft, ChevronRight, CircleAlert, CircleCheck, Clock, Info, LogOut, Menu, Moon, PanelLeftClose, PanelLeftOpen, Pencil, Plus, RefreshCw, SlidersHorizontal, Sun, Trash2, X | none yet (replaces the Unicode glyph icons and the `Login`/`MessageCard` inline SVGs) |
| Alert | Feedback ([alert](https://daisyui.com/components/alert/)) | `variant` (info, success, warning, error; soft tint with `base-content` text and a full status-colour border, not daisyUI's raw `alert-soft` text, which fails contrast on light themes), `title` + `headingLevel` (required with `title`: 2, 3, 4, or `null` for bold text that is not a heading), `icon` (default on, decorative, status colour), `action`, `live` (`assertive` = `role=alert`, `polite` = `role=status`, omitted = static), `<div>` attributes | ui/icons (replaces `Alert`, `MessageCard` and the inline yellow warnings in `Calendar`/`Step1Form`) |
| Tooltip, FloatingTooltip | Feedback ([tooltip](https://daisyui.com/components/tooltip/)) | Tooltip (daisyUI CSS, above the trigger, shown on hover and keyboard focus `:focus-visible`, not after a mouse click): `content`, one focusable child (gets `aria-describedby`); Esc hides it until hover and focus leave and is consumed (does not also close a dialog). FloatingTooltip (programmatic, portal on `document.body`, or inside an open ui/Modal's dialog): `open`, `anchor` (element; gets `aria-describedby` while open), `onClose` (close button "Close tooltip", Esc, timeout), `timeout` (ms; not restarted when re-opened on the same anchor), `<div>` attributes. No blur close, no scroll tracking or viewport clamping. The caller also writes the message into a persistent `role="status"` region, because a description added to a focused element is not announced | ui/Button, ui/icons (replaces `Tooltip`; FormField and GeneralSettings use Tooltip, the blocked dates use FloatingTooltip) |
| Modal | Actions ([modal](https://daisyui.com/components/modal/)) | `open`, `onClose` (close button "Close", Esc, a backdrop click that also started on the backdrop, and a native close; the parent sets `open` to false), `title` (required: `h2` and accessible name), `footer` (`modal-action` row), `<dialog>` attributes. Native `showModal()` in a portal; page scroll is locked by daisyUI's `:root:has(.modal[open])`; bottom sheet below `sm`, centred above (legacy was full screen below 768px); title and footer stay in view, the body scrolls. Provides `ModalPortalContext` (the dialog) for FloatingTooltip | ui/Button, ui/icons (replaces `Modal`) |
| Swap, SwapCheckbox | Actions ([swap](https://daisyui.com/components/swap/)) | Swap (button, `swap-rotate`): `label` (accessible name), `active`, `state` (`pressed` = `aria-pressed`, default; `expanded` = `aria-expanded`, e.g. with `aria-controls`), `on`, `off`, `<button>` attributes (add `btn` classes via `class`); exposes `data-active`. SwapCheckbox (controlled checkbox): `label`, `checked`, `onChange(checked)`, `on`, `off`; other attributes go on the visually hidden checkbox, `class` on the label; truly controlled (a change the parent ignores is undone); no disabled styling yet | ui/ThemeController (planned: the AdminLayout drawer toggle replacing the AdminSidebar ☰/✕) |
| ThemeController | Actions ([theme controller](https://daisyui.com/components/theme-controller/)) | `lightTheme`, `darkTheme` (`ThemeName` from `shared/styles/themes.ts`, e.g. `admin-light`/`admin-dark`; fixed for its lifetime), `onChange(theme, mode)`, other SwapCheckbox props (`class`, checkbox attributes). A "Dark mode" SwapCheckbox (Sun/Moon) that sets `<html data-theme>`; initial state read from the current `data-theme` (anything but `lightTheme` counts as dark); one instance per page (external `data-theme` changes are not tracked); stores nothing (the admin shell persists, subtask 33). Not daisyUI's CSS `theme-controller` input: its `:root:has(...)` state lives only in the checkbox and would fight the `data-theme` that `public/js/theme.js` sets before first paint | ui/Swap, ui/icons (new; planned for the admin drawer) |
| Fieldset | Data input ([fieldset](https://daisyui.com/components/fieldset/), [label](https://daisyui.com/components/label/)) | `label` (string), `htmlFor` (defaults to the child's `id`), `required` (visual `*`, hidden from AT; also set `required` on the control), `hint`, `error` (`role=alert`; replaces the hint; sets `aria-invalid`), `tooltip` (CSS ui/Tooltip on a "More about <label>" Info button; hover and keyboard focus, not tap), one control child that spreads ARIA attributes onto its native element (gets merged `aria-describedby`; loading/empty states go outside the Fieldset). The `*` sits outside the `<label>`, so the accessible name is the plain label, `<div>` attributes. Root is a `<div class="fieldset text-sm">` around a `<label>`, not a `<fieldset>`, because it labels one control | ui/Button, ui/Tooltip, ui/icons (replaces `FormField`, 31 call sites) |
| Input | Data input ([input](https://daisyui.com/components/input/), [validator](https://daisyui.com/components/validator/)) | `type` (text, email, tel, password, number, date, time; default text), `validator` (red border on `:user-invalid`, green on `:user-valid`), `<input>` attributes (all on the native element). Full width. `aria-invalid` (set by ui/Fieldset on error; any value but false) adds `input-error`. With preact/compat loaded, `onChange` fires per keystroke: use `onInput`, or `onBlur` to commit. No sizes, label, hint or error text (no current use; ui/Fieldset owns the messages) | ui/Fieldset (replaces `Input`) |
| Select | Data input ([select](https://daisyui.com/components/select/)) | `options` (`{ value, label }[]`, string or number values), `value` (empty, missing or not an option selects the placeholder, or the first option without one), `placeholder` (disabled empty first option; never submitted), `<select>` attributes (all on the native element). Full width. `aria-invalid` adds `select-error`. Single-choice only (`multiple`/`size` owned). No children mode, sizes or error text (no current use; ui/Fieldset owns the messages) | ui/Fieldset (replaces `Select`) |
| Textarea | Data input ([textarea](https://daisyui.com/components/textarea/)) | `rows` (default 3), `<textarea>` attributes (all on the native element). Full width. `aria-invalid` adds `textarea-error`. With preact/compat loaded, `onChange` fires per keystroke: use `onInput`, or `onBlur` to commit. No sizes, hint or error text (the legacy `hint` moves to ui/Fieldset) | ui/Fieldset (replaces `Textarea`) |
| Toggle | Data input ([toggle](https://daisyui.com/components/toggle/)) | `label` (required accessible name; rich content allowed, e.g. `Closed{' '}<span class="sr-only">on Monday</span>`; keep the `{' '}` before the span), `hideLabel` (sr-only), `checked`, `onChange(checked)`, `disabled` (dims the row), checkbox attributes (`id`, `aria-describedby`… go on the checkbox), `class` on the label row. Always `toggle-primary`: on = primary border and knob on a `base-100` track (daisyUI look), not the legacy filled primary track; label `text-sm`. Truly controlled (an ignored change is undone). No colour or size variants (no current use) | none yet (replaces `ToggleSwitch`; the Dashboard toggle gains the accessible name it lacks today) |
| Badge | Data display ([badge](https://daisyui.com/components/badge/)) | `variant` (default = plain `badge`, base-100 fill, lighter than the legacy grey chip; primary = solid `badge-primary`, the legacy `today` look, not the legacy tinted `primary`), `<span>` attributes. One size, `badge-sm` (legacy 0.75rem) | none yet (replaces `Badge`: BookingCard guest count, DateNav "today" in subtask 35) |
